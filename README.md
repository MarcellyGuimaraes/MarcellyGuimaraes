### Sobre

Desenvolvedora Full Stack com experiência em construir e manter aplicações web do back ao front. No **back-end**, trabalho com **PHP/Laravel** e **Node.js/TypeScript**, desenvolvendo APIs RESTful, integrações entre serviços e lógica de negócio sobre bancos de dados relacionais. No **front-end**, atuo com **React/Next.js**. Gosto de entregar projeto que resolve o problema de verdade — código de qualidade, arquitetura em camadas e boas práticas, não só "no ar".

Atualmente **aberta a oportunidades** como desenvolvedora back-end ou full stack, remoto.
